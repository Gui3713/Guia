Guia de bolso git

Comandos Essenciais

git init

cria um novo repositório git na pasta atual

git add .

prepara as alterações feitas nos arquivos do projeto para serem salvas no proximo historico

git commit -m "[Mensagem de Commit]"

salva as alterações com uma mensagem descritiva

git push -u origin main

manda as alterações ao repositório

Dica: lembre-se do espaço no comando git add .
